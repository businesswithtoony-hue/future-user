# Future User — community node

This public repository currently contains release information only. The user app source and binaries are not published here while the node runtime receives a separate security review.

## Platform availability

- Windows x64: a local build exists, but there is no public verified download link in this repository.
- Linux and macOS: no verified release build is published.
- Older Macs may not support the current Electron runtime.

A website cannot silently run CMD/Terminal commands. Joining must happen through an explicitly launched, user-facing client with a clear consent step. Node participation can improve peer distribution only when nodes are independently reachable and peer discovery is resilient; the current network has not yet been shown to meet that bar.

Mining consumes device resources. It must remain a separate opt-in action, and no reward or income is guaranteed.

## Security

No administrator UI, credentials, wallet files, recovery phrases, private keys, RPC tokens, or node databases are published in this repository.
